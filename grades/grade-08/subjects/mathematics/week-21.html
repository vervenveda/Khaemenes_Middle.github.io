Slope and intercept · Learn and represent

Vocabulary in context: Name the quantities, relationships, domain and units used in the questions.

Worked mathematical model: Slope is vertical change divided by horizontal change; intercept is the predicted value at x=0. Today's model uses a=3 and b=3; explain how the example applies to this week's evidence theme.

Misconception checkpoint: Coordinate subtraction must use the same point order in numerator and denominator.

Independent reasoning challenges:

  1. Find slope between (0,3) and (3,12).
  2. For y=3x−3, identify its intercept.
  3. At slope 3, x grows by 4: predicted rise?
  4. Find y at x=2 for y=3x−3.

Independent self-check: Recompute using inverse operations, a substitution, an alternative diagram or unit analysis before opening the key.

Teacher solution key (open after attempting)
  1. 3
  2. -3
  3. 12
  4. 3
