Define function inputs and outputs · Mathematics laboratory

Vocabulary in context: Define the important quantities and units in the worked model; explain them in your own words.

Worked mathematical model: For f(x)=2x−3, f(4)=5. Each allowed input must correspond to exactly one output.

Misconception checkpoint: Different inputs may share an output; one input must not have two outputs in a function.

Independent reasoning challenges:

  1. Find f(0) for f(x)=2x−3.
  2. Find f(5).
  3. Does input 2 with outputs 1 and 4 define a function?
  4. Find f(−1).

Independent self-check: Verify by substitution, inverse operations, unit comparison or a second representation before inspecting the answer key.

  2. 7

Identify linear and nonlinear functions · Mathematics laboratory

Vocabulary in context: Define the important quantities and units in the worked model; explain them in your own words.

Worked mathematical model: f(x)=3x+1 changes by 3 for each +1 in x; g(x)=x² has varying first differences.

Misconception checkpoint: A curved graph or varying difference cannot be labeled linear simply because it has a rule.

Independent reasoning challenges:

  1. For f(x)=3x+1 find f(2).
  2. For f(x)=3x+1 find f(3).
  3. For g(x)=x² find g(2).
  4. For g(x)=x² find g(3).

Independent self-check: Verify by substitution, inverse operations, unit comparison or a second representation before inspecting the answer key.

Use function notation · Mathematics laboratory

Vocabulary in context: Define the important quantities and units in the worked model; explain them in your own words.

Worked mathematical model: If f(x)=5−2x, f(3)=−1 by substituting 3 for x.

Misconception checkpoint: f(3) means output at input 3, not f multiplied by 3.

Independent reasoning challenges:

  2. Find f(−2).

Compare functions in context · Mathematics laboratory

Vocabulary in context: Define the important quantities and units in the worked model; explain them in your own words.

Worked mathematical model: A(x)=3x+8 and B(x)=5x+2 cross at x=3, because both equal 17.

Misconception checkpoint: One function being cheaper at x=0 does not make it cheaper for every x.

Independent reasoning challenges:

  3. Compute A(3).

Make a function claim with evidence · Mathematics laboratory

Vocabulary in context: Define the important quantities and units in the worked model; explain them in your own words.

Worked mathematical model: For h(x)=4x−1, h(2)=7 and h(3)=11, so output rises 4 for +1 input.

Misconception checkpoint: A modeled relationship does not establish that real observed data follow the model exactly.

Independent reasoning challenges:

  1. Find h(5).
  2. Find h(0).
  3. Find output change from x=5 to x=7.
  4. State the constant slope.

Independent self-check: Verify by substitution, inverse operations, unit comparison or a second representation before inspecting the answer key.
