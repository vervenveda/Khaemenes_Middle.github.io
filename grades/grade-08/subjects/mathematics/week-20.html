Require evidence, calculation, model, vocabulary, citation note, or high-school-level explanation. Close with a defense or reflection: The high-school-ready part of my work is ____.

Evidence: Student work sample, teacher observation, oral explanation, correction/revision, and weekly subject mastery evidence.

Functions and domains · Learn and represent

Vocabulary in context: Name the quantities, relationships, domain and units used in the questions.

Worked mathematical model: Evaluate f(x) by substituting a particular input for the function variable. Today's model uses a=2 and b=5; explain how the example applies to this week's evidence theme.

Misconception checkpoint: Function notation means output at an input, not multiplication by the function name.

Independent reasoning challenges:

  1. Given f(x)=2x−5, find f(2).
  2. Find f(0) for f(x)=2x−5.
  3. For f(x)=2x−5, find f(4).
  4. Solve f(x)=1, if f(x)=2x−5.

Independent self-check: Recompute using inverse operations, a substitution, an alternative diagram or unit analysis before opening the key.

Teacher solution key (open after attempting)
  1. -1
  2. -5
  3. 3
  4. x=3
