Week 16 · Language Arts & Literacy

Forces, Motion, and Systems

How do forces and systems explain motion?

Monday: Describe motion accurately

Focus: Describe motion accurately.

Learn: Technical writing defines distance, time, speed and direction before interpreting movement. A fictional object traveling 12 meters in four seconds has average speed 3 meters per second.

Practice and evidence: Write a clear caption for a simulated distance-time table with units.

Tuesday: Explain graph evidence

Focus: Explain graph evidence.

Learn: A position-time graph can show changing position; the steepness of a straight segment describes its rate of change. An upward line does not by itself identify the cause of motion.

Practice and evidence: Describe an original graph with points (0,0), (2,6), (4,12), explaining which axis represents seconds and which meters.

Wednesday: Separate causes and correlations

Focus: Separate causes and correlations.

Learn: A push or pull can influence motion, but evidence about one object cannot establish how all objects behave. An explanation distinguishes the observed change from the proposed force.

Practice and evidence: Edit a fictional report that incorrectly claims a faster recorded speed proves a greater applied force.

Thursday: Use variable language

Focus: Use variable language.

Learn: A simplified constant-speed model d=vt relates distance d, speed v and time t under stated assumptions. Words such as if, when, and provided that explain limits.

Practice and evidence: Write a paragraph interpreting d=3t for t=1, 2, 3 seconds with assumptions noted.

Friday: Write an evidence-based motion brief

Focus: Write an evidence-based motion brief.

Learn: Effective technical writing combines a claim, labeled graph, correct rate, fair reasoning, and a discussion of uncertainties.

Practice and evidence: Submit a 160-word fictional motion report with graph and one corrected overclaim. Rubric: quantities 6, evidence 5, cause/effect 5, editing 4.
