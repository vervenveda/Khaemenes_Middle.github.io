Week 07 · Language Arts & Literacy

Coordinate Planes and Geography

How can coordinates help us describe place, movement, and patterns?

Monday: Describe a coordinate map

Focus: Describe a coordinate map.

Learn: A coordinate map identifies locations using ordered pairs (x,y), where x gives the horizontal position and y the vertical. A precise explanation names the origin, directions and scale.

Practice and evidence: Draw a fictional neighborhood grid with a library at (2,3) and school at (−1,2). Write four full sentences that describe locations correctly.

Tuesday: Use spatial prepositions

Focus: Use spatial prepositions.

Learn: Words such as above, below, west of and between depend on an agreed reference system. On a standard coordinate plane, (2,3) is three units above the horizontal axis.

Practice and evidence: Write six clear location sentences about an original grid, then annotate which statement depends on orientation.

Wednesday: Integrate text and map

Focus: Integrate text and map.

Learn: A map can support an explanatory text only when symbols and scale match the claims. A fictional grid point is not automatically a real latitude-longitude coordinate.

Practice and evidence: Write a descriptive paragraph for a route from (−2,1) to (1,1), using the legend and an exact three-unit eastward displacement.

Thursday: Revise ambiguous directions

Focus: Revise ambiguous directions.

Learn: Directions such as 'go up a little' cannot be tested. Replace vague language with measurable steps and a defined starting location.

Practice and evidence: Edit four confusing fictional instructions. Test them by plotting the destination and note any remaining uncertainty.

Friday: Publish a clear geography guide

Focus: Publish a clear geography guide.

Learn: Effective explanatory writing connects coordinates, key terms, map labels, distance, scale and thoughtful revision.

Practice and evidence: Present a labeled fictional map and a 150-word route guide with ordered pairs, an explicit starting point and verified directions. Rubric: spatial accuracy 6, clear language 5, map-text evidence 5, revision 4.
