Week 33 · Language Arts & Literacy

Technology, Data, and Ethical Creation

How can tools strengthen evidence without replacing judgment?

Monday: Read algorithm instructions critically

Focus: Read algorithm instructions critically.

Learn: Technical directions use precise definitions, sequences and conditions; vague wording can cause inconsistent outcomes.

Practice and evidence: Annotate a fictional sorting procedure and rewrite two ambiguous instructions.

Tuesday: Evaluate data narratives

Focus: Evaluate data narratives.

Learn: A chart's headline may claim more than its measurements can establish.

Practice and evidence: Compare a fictional graph caption to its described axes and correct a misleading claim.

Wednesday: Write transparent explanations

Focus: Write transparent explanations.

Learn: Readers need definitions, example inputs and known limitations to evaluate a computational result.

Practice and evidence: Draft a plain-language explanation of an invented classroom data sorter.

Thursday: Edit for access

Focus: Edit for access.

Learn: A readable guide needs clear headings, wrapped text and alternatives to color-only instructions.

Practice and evidence: Revise an offline app's fictional help page for a 255px-wide layout.

Friday: Publish an evidence-aware guide

Focus: Publish an evidence-aware guide.

Learn: Technical writing should distinguish what a tool does from what it cannot infer.

Practice and evidence: Submit a 180-word tool review with example, source notes, limitations and revision. Rubric: accuracy 6, evidence 6, clarity 4, access 4.
