Week 08 · Science & Engineering

Expressions and Algebraic Thinking

How can symbols represent ideas in math, language, and culture?

Monday: Variables in models

Focus: Variables in models.

Learn: A variable represents a quantity that can change. In a fictional experiment, t may represent elapsed time in minutes, and d distance in meters. A model d=2t describes constant speed 2 m/min, not every real movement.

Practice and evidence: Make a two-column t and d table for t=0,1,2,3 using the simulated relationship.

Tuesday: Independent and dependent quantities

Focus: Independent and dependent quantities.

Learn: An independent variable is chosen or recorded as an input; a dependent variable changes in response within a model. The labels describe design, not automatic proof of cause.

Practice and evidence: Graph the simulated values for d=2t and identify axes and units.

Wednesday: Substitute responsibly

Focus: Substitute responsibly.

Learn: Substitution evaluates a model at a specified value. In d=2t, t=4 predicts 8 meters; predictions depend on assumptions.

Practice and evidence: Evaluate the model for t=4 and t=5, showing units and one limitation.

Thursday: Compare models

Focus: Compare models.

Learn: The fictional relations d=2t and d=3t describe different constant rates. They can be compared at the same input but not treated as observed real measurements.

Practice and evidence: Create a comparison table for t=1,2,3 and explain why one model predicts a greater distance.

Friday: Scientific model portfolio

Focus: Scientific model portfolio.

Learn: A scientific model needs defined variables, units, evidence, calculations, and an explicit statement of its limitations.

Practice and evidence: Submit a labeled graph, substitution work, and CER paragraph about simulated distances. Rubric: variable definitions 5, computations 6, interpretation 5, limitations 4.
