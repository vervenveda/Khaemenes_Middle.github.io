Week 34 · Science & Engineering

A++ Big Question Capstone Research

What serious question can I investigate with evidence, calculation, and design?

Monday: Frame a testable hypothesis

Focus: Frame a testable hypothesis.

Learn: Scientific components require measurable predictions, controls and safety boundaries.

Practice and evidence: Define an ethical question about a fictional classroom plant-water model.

Tuesday: Select measurable variables

Focus: Select measurable variables.

Learn: Independent, dependent and controlled variables must be distinguishable.

Practice and evidence: Write a three-trial plan using simulated non-sensitive data.

Wednesday: Create a model

Focus: Create a model.

Learn: Models simplify phenomena and must name assumptions.

Practice and evidence: Draw a hypothetical ecosystem resource-flow model with units.

Thursday: Compare predictions

Focus: Compare predictions.

Learn: Evidence quality depends on checking models against observations and reporting uncertainty.

Practice and evidence: Compare three invented results to model predictions and explain two limitations.

Friday: Submit an inquiry report

Focus: Submit an inquiry report.

Learn: A scientific conclusion should not imply unsupported causation.

Practice and evidence: Submit method, chart, model and bounded conclusion. Rubric: method 6, data 6, reasoning 4, ethics 4.
