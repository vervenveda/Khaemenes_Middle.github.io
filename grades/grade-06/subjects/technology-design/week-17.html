Week 17 · Technology, Design & Tools

Midyear Portfolio and Assessment

How can I prove growth across every subject?

Monday: Audit previous prototypes

Focus: Audit previous prototypes.

Learn: A midyear digital portfolio can contain pseudocode, interface sketches and test logs with original dates and revisions.

Practice and evidence: Choose a calculator or chart design and list its expected inputs and outputs.

Tuesday: Review validation

Focus: Review validation.

Learn: An algorithm must reject malformed inputs and invalid denominators; a test log records expected versus observed results.

Practice and evidence: Write four positive and four negative tests for an earlier fictional calculator.

Wednesday: Improve mobile access

Focus: Improve mobile access.

Learn: A 255px display needs wrapping text, labeled fields, keyboard-compatible controls and non-color error messages.

Practice and evidence: Revise a narrow-screen wireframe and provide an accessible table alternative.

Thursday: Document a regression fix

Focus: Document a regression fix.

Learn: A corrected program needs a reproducible test case and a clear explanation of its behavior before and after.

Practice and evidence: Write a fictional bug report with reproduction steps and verification outcome.

Friday: Certify a technical portfolio

Focus: Certify a technical portfolio.

Learn: A complete record identifies the project, code logic, tests, accessibility decisions and learner reflection.

Practice and evidence: Submit design, eight tests and revision notes. Rubric: function 6, tests 6, access 5, clarity 3.
