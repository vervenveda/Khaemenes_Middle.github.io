Week 12 · Technology, Design & Tools

Geometry: Area, Surface Area, and Design

How do measurements help designers plan efficient spaces?

Monday: Represent dimensions

Focus: Represent dimensions.

Learn: A digital design table should label each dimension and its unit. For a 3 cm by 4 cm rectangle the area formula gives 12 cm².

Practice and evidence: Create a table with shape ID, width, height, units and computed area.

Tuesday: Algorithm for area

Focus: Algorithm for area.

Learn: A paper algorithm sets area=width*height. It should reject negative dimensions and explain missing input.

Practice and evidence: Write pseudocode for rectangle area with positive numeric inputs.

Wednesday: Model a cube net

Focus: Model a cube net.

Learn: A six-face cube net with side s has surface area 6s². A program must distinguish squared units from edge lengths.

Practice and evidence: Create three test cases for s=1,2,3 and document expected surface areas.

Thursday: Accessible small-screen layouts

Focus: Accessible small-screen layouts.

Learn: A 255px design should wrap labels, provide readable errors and show units in text rather than only visual symbols.

Practice and evidence: Sketch a 255px-wide area calculator with two labeled input fields, a result region and an error message.

Friday: Test and document

Focus: Test and document.

Learn: A trustworthy prototype tests normal inputs, missing values and invalid dimensions, then records revisions.

Practice and evidence: Submit pseudocode, a wireframe and five-case test log. Rubric: formula 6, validation 5, accessibility 5, revision 4.
