Week 35 · Technology, Design & Tools

Capstone Studio and Oral Defense

How can I make my evidence clear enough to defend publicly?

Monday: Audit the prototype

Focus: Audit the prototype.

Learn: An oral defense is stronger when expected and actual tool behaviors are documented.

Practice and evidence: Write a three-case test table for a fictional offline model.

Tuesday: Trace data provenance

Focus: Trace data provenance.

Learn: Prototypes must distinguish sample data from verified sources and record missing fields.

Practice and evidence: Create a source log with one uncertainty marker.

Wednesday: Debug a failure

Focus: Debug a failure.

Learn: A failure report should identify reproduction steps, cause hypotheses and fixes.

Practice and evidence: Trace a fictional double-counting spreadsheet bug.

Thursday: Verify accessible presentation

Focus: Verify accessible presentation.

Learn: Controls, narrow-screen layouts and explanatory text must remain usable without audio or color cues.

Practice and evidence: Plan 255px screen, keyboard and reset tests.

Friday: Demonstrate and defend

Focus: Demonstrate and defend.

Learn: A responsible demo states input limits, known bugs, privacy decisions and revisions.

Practice and evidence: Submit a test report and concise demonstration script. Rubric: correctness 6, testing 6, access 4, privacy 4.
