Week 16 · Technology, Design & Tools

Forces, Motion, and Systems

How do forces and systems explain motion?

Monday: Model motion data

Focus: Model motion data.

Learn: A table requires time, distance and units. A fictional object at 0,3,6,9 meters at 0,1,2,3 seconds shows equal distance increments.

Practice and evidence: Create an offline data table and label simulated observations.

Tuesday: Compute average speed

Focus: Compute average speed.

Learn: A simple algorithm calculates distance divided by elapsed time, provided elapsed time is greater than zero.

Practice and evidence: Write pseudocode computing 12 meters / 4 seconds = 3 m/s.

Wednesday: Validate motion inputs

Focus: Validate motion inputs.

Learn: Non-numeric, missing and zero elapsed-time inputs require understandable errors; a graph should not silently display invalid results.

Practice and evidence: Specify six normal and error tests for a paper speed calculator.

Thursday: Make accessible graphs

Focus: Make accessible graphs.

Learn: At a 255px width, distance-time chart labels must wrap and text-table alternatives should show points clearly.

Practice and evidence: Draw a narrow-screen tool with accessible input, calculated result and data table.

Friday: Test the prototype

Focus: Test the prototype.

Learn: A usable prototype documents correct formulas, errors, rate units and one revision.

Practice and evidence: Submit pseudocode, six tests and 255px wireframe. Rubric: algorithm 6, tests 6, accessibility 5, documentation 3.
