Week 07 · Technology, Design & Tools

Coordinate Planes and Geography

How can coordinates help us describe place, movement, and patterns?

Monday: Coordinate data formats

Focus: Coordinate data formats.

Learn: A map data record should label x and y explicitly. Swapping them changes location. A fictional point at (−2,3) has x=−2 and y=3.

Practice and evidence: Create a table with identifier, x, y and label for three fictional locations; mark data as simulated.

Tuesday: Map layers

Focus: Map layers.

Learn: Layers separate information such as landmarks, pathways and natural features. Controls should let users distinguish layers even without color.

Practice and evidence: Sketch a local offline map interface with three toggleable layers and text labels.

Wednesday: Validate coordinates

Focus: Validate coordinates.

Learn: A four-quadrant practice grid may permit x and y from −5 to +5; entries beyond this range should receive a readable error, not silently disappear.

Practice and evidence: Write five test cases including valid negative points, the origin, swapped coordinates and out-of-range input.

Thursday: Build an accessible map view

Focus: Build an accessible map view.

Learn: Mobile maps require readable labels, keyboard-friendly controls and descriptions that do not rely on pin color. A 255px layout should avoid cropped words.

Practice and evidence: Draw a 255px-wide paper UI showing title, coordinate entry fields, a layer list, and clear textual location output.

Friday: Prototype and test

Focus: Prototype and test.

Learn: A useful digital map prototype preserves axis order, validates entries and documents changes after testing.

Practice and evidence: Submit a paper wireframe, fictional location table and five-case test log. Rubric: data accuracy 6, accessibility 5, validation 5, revision 4.
