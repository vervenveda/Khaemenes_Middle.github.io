Week 28 · Technology, Design & Tools

World Languages and Cultural Communication

How does language carry culture and connection?

Monday: Inspect Unicode text

Focus: Inspect Unicode text.

Learn: Digital systems store many scripts using Unicode, but a code point is not the same as a visual character.

Practice and evidence: Make a table of sample multilingual text and label any display uncertainties.

Tuesday: Consider text direction

Focus: Consider text direction.

Learn: Right-to-left and mixed-direction text require intentional interface design.

Practice and evidence: Sketch an offline form supporting both left-to-right and right-to-left sample labels.

Wednesday: Build accessible instructions

Focus: Build accessible instructions.

Learn: Readable headings, semantic labels and clear language support multilingual users.

Practice and evidence: Design a 255px-wide paper or offline HTML welcome interface with descriptive controls.

Thursday: Test translation boundaries

Focus: Test translation boundaries.

Learn: Machine translation can mistranslate names, idioms and instructions; important content needs human review.

Practice and evidence: Write four offline test cases for missing translations, long text and directional layout.

Friday: Document an ethical prototype

Focus: Document an ethical prototype.

Learn: Public displays must avoid exposing student names or inventing authoritative translations.

Practice and evidence: Submit a three-screen interface mockup with accessibility and review checklist. Rubric: layout 5, access 6, accuracy 5, privacy 4.
