Week 05 · Technology, Design & Tools

Fraction Division and Procedural Writing

How can models explain division when the numbers are fractions?

Monday: Algorithmic sequence

Focus: Algorithmic sequence.

Learn: An algorithm is an ordered list of steps. A reliable algorithm names inputs, actions, expected output, and conditions for stopping.

Practice and evidence: Write pseudocode for splitting a paper strip into four equal parts, and state how to verify equality.

Tuesday: Fractional inputs and outputs

Focus: Fractional inputs and outputs.

Learn: Digital tools can use numbers such as 1/2 and 1/4, but errors arise when units or data types are ambiguous. Dividing 3/4 by 1/4 should give three groups.

Practice and evidence: Create a paper test table for four fractional examples with input, expected result, and explanation.

Wednesday: Debug imprecise instructions

Focus: Debug imprecise instructions.

Learn: A bug can arise from an omitted step or faulty assumption. Debugging identifies the first step that produces an incorrect state.

Practice and evidence: Read a fictional algorithm that divides 2/3 into sixths but labels the result as two pieces; correct it to four pieces with a diagram.

Thursday: Document a repeatable process

Focus: Document a repeatable process.

Learn: Documentation should include numbered steps, valid examples, edge cases, and accessible language. Do not expose private student files while demonstrating a tool.

Practice and evidence: Design a 255px-wide mobile instruction page with a short step list, readable fraction notation, and visible keyboard focus.

Friday: Test a small prototype

Focus: Test a small prototype.

Learn: A prototype should pass known examples and show useful correction evidence.

Practice and evidence: Submit the fraction-strip pseudocode, three test cases, a readable UI sketch, and a bug-fix note. Rubric: correctness 6, algorithm 5, accessibility 5, testing 4.
