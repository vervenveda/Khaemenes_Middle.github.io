Week 33 · Technology, Design & Tools

Technology, Data, and Ethical Creation

How can tools strengthen evidence without replacing judgment?

Monday: Plan a clear data table

Focus: Plan a clear data table.

Learn: Column names, consistent units and source notes help records stay understandable.

Practice and evidence: Make a four-column fictional dataset with missing-value labels.

Tuesday: Write algorithm steps

Focus: Write algorithm steps.

Learn: Algorithms describe repeatable operations and must specify input and output.

Practice and evidence: Write pseudocode to compute totals from simulated data.

Wednesday: Debug an incorrect result

Focus: Debug an incorrect result.

Learn: Testing a sample with known answers can uncover formula and sorting mistakes.

Practice and evidence: Trace a fictional spreadsheet sum that counts one row twice.

Thursday: Check accessibility and privacy

Focus: Check accessibility and privacy.

Learn: Offline tools still need readable controls, safe reset behavior and limited data retention.

Practice and evidence: Sketch a 255px interface and write five navigation/identity-isolation tests.

Friday: Document a small tool

Focus: Document a small tool.

Learn: A reliable project has instructions, examples, provenance and known limits.

Practice and evidence: Submit offline prototype/specification with tests and reflection. Rubric: correctness 6, traceability 6, access 4, privacy 4.
