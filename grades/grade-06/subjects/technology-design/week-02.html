Week 02 · Technology, Design & Tools

Evidence, Annotation, and Ratios

How do evidence and comparison help us understand complex ideas?

Monday: Organize files clearly

Focus: Organize files clearly.

Learn: Good folder hierarchies identify grade, course, week, and document purpose. Meaningful names help avoid accidentally overwriting evidence.

Practice and evidence: Sketch a Grade06/Science/Week02 folder with notes, graph, and reflection files named clearly.

Tuesday: Version control basics

Focus: Version control basics.

Learn: A version is a saved stage of work. Keeping the original and a revised copy allows comparison and recovery.

Practice and evidence: Invent a three-step revision history with timestamps and a short description of what changed.

Wednesday: Data and metadata

Focus: Data and metadata.

Learn: Metadata describes a file, such as title, date, creator, or subject; private personal data should not appear on public repository pages.

Practice and evidence: Create a safe metadata card for a fictional classroom graph, omitting addresses and credentials.

Thursday: Accessible document design

Focus: Accessible document design.

Learn: A readable document uses headings, contrast, visible focus, meaningful labels, and layouts that do not crop at narrow widths.

Practice and evidence: Sketch a 255px-wide folder browser showing readable file names and a keyboard-accessible download link.

Friday: File-management prototype

Focus: File-management prototype.

Learn: A useful prototype can be tested against tasks and improved after feedback.

Practice and evidence: Present a paper file organizer, test two retrieval tasks, and record one revision. Rubric: organization 6, privacy 5, accessibility 5, testing 4.
