Week 03 · Technology, Design & Tools

Rates, Unit Rates, and Informational Text

How can rates and text structures explain change?

Monday: Create a clean data table

Focus: Create a clean data table.

Learn: A spreadsheet holds observations in rows and variables in columns. A column heading should specify units, such as Distance (km) and Time (h).

Practice and evidence: Create a paper or local spreadsheet with simulated travel records 12 km/3 h, 15 km/3 h, and 18 km/6 h.

Tuesday: Calculate unit rates

Focus: Calculate unit rates.

Learn: A formula divides distance by time; a spreadsheet example is =A2/B2 when A2 contains distance and B2 contains time. Check that time is not zero.

Practice and evidence: Calculate 4, 5, and 3 km/h from the example data, labeling the rate column and validating each result.

Wednesday: Design a readable graph

Focus: Design a readable graph.

Learn: Graph axes, labels, and consistent scales enable fair comparison. A graph must not invent values between observations.

Practice and evidence: Sketch a bar chart of the three fictional trip rates with a zero baseline, legible labels, and meaningful alt-text description.

Thursday: Document data provenance

Focus: Document data provenance.

Learn: A record should explain whether its source is observed, published, or simulated, when it was prepared, and limitations. Avoid putting private learner records on public pages.

Practice and evidence: Add a small metadata table noting 'Khaemenes Academy fictional practice data,' units, and revision date.

Friday: Audit and improve a data artifact

Focus: Audit and improve a data artifact.

Learn: Testing checks arithmetic, clarity, and accessibility. A peer should be able to reproduce calculations without guessing.

Practice and evidence: Submit your table, formulas or paper arithmetic, graph, and one corrected usability issue. Rubric 20: calculation 6, metadata 4, accessibility 5, verification 5.
