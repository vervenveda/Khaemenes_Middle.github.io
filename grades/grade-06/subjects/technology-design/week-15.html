Week 15 · Technology, Design & Tools

Thermal Energy and Phase Change

How does energy explain changes in matter?

Monday: Represent a time series

Focus: Represent a time series.

Learn: An offline data table can store elapsed minutes and temperature in °C. A fictional series at t=0,1,2,3 is 0,2,4,4 °C.

Practice and evidence: Create a table with time, temperature and units; label all values as simulated.

Tuesday: Calculate a simple rate

Focus: Calculate a simple rate.

Learn: The average temperature change between 0 and 2 minutes for values 0 and 4 °C is 2 °C per minute; this does not imply all intervals change equally.

Practice and evidence: Write pseudocode for (final-start)/(endTime-startTime), checking the denominator.

Wednesday: Detect a flat interval

Focus: Detect a flat interval.

Learn: A plateau occurs when consecutive recorded values are equal. A program should report an interval without automatically asserting a phase change.

Practice and evidence: Create five unit tests for consecutive and changing values.

Thursday: Accessible mobile visualization

Focus: Accessible mobile visualization.

Learn: At 255px width, chart values need text alternatives, wrapped labels, clear scales and readable error messages.

Practice and evidence: Sketch a narrow chart-and-table interface for a fictional warming sequence.

Friday: Document the prototype

Focus: Document the prototype.

Learn: A trustworthy chart tool checks data shape, time order, unit labels and limitations.

Practice and evidence: Submit offline pseudocode, five tests and accessible wireframe. Rubric: computation 6, testing 5, access 5, notes 4.
