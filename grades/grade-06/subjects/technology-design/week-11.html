Week 11 · Technology, Design & Tools

Statistics: Questions, Data, and Distribution

How can data answer questions while still requiring judgment?

Monday: Choose a useful data structure

Focus: Choose a useful data structure.

Learn: A compact offline dataset could store simulated observations [2,3,3,4,8]. Every item needs a consistent meaning and unit.

Practice and evidence: Write a five-entry table with index, value and unit; show how missing entries would be labeled.

Tuesday: Generate frequencies

Focus: Generate frequencies.

Learn: A frequency table counts repeated observations. For [2,3,3,4,8], the value 3 occurs twice, while the others occur once.

Practice and evidence: Write pseudocode that counts occurrences and verify the result manually.

Wednesday: Validate data and labels

Focus: Validate data and labels.

Learn: A program should reject nonnumeric values when arithmetic is required. A chart needs a title and labeled axes, not only bars or colors.

Practice and evidence: Define four test cases: numeric, zero, missing and nonnumeric values, with clear text outcomes.

Thursday: Design a small chart view

Focus: Design a small chart view.

Learn: A 255px-wide interface needs scroll-safe labels, predictable focus, a textual data summary and usable controls.

Practice and evidence: Sketch a mobile-friendly chart panel with a table alternative and a visible description of the median.

Friday: Document a tested prototype

Focus: Document a tested prototype.

Learn: A responsible statistical tool distinguishes input data, calculations and uncertainty.

Practice and evidence: Submit offline pseudocode, frequency table, 255px wireframe and test log. Rubric: counts 6, testing 5, access 5, documentation 4.
