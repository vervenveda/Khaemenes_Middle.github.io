Week 19 · Technology, Design & Tools

Light, Vision, and Media Interpretation

How does light shape what we see and how we interpret media?

Monday: Describe a visual model

Focus: Describe a visual model.

Learn: An interface can represent ray paths with lines and labels, but a diagram is not a verified optical measurement.

Practice and evidence: Draft a labeled data schema for a fictional incidence/reflection pair.

Tuesday: Calculate reflected angle

Focus: Calculate reflected angle.

Learn: A simple ideal-mirror model sets reflected angle equal to incident angle, measured from the surface normal.

Practice and evidence: Write pseudocode that accepts 30 degrees and returns 30 degrees with a label.

Wednesday: Validate input

Focus: Validate input.

Learn: Reject missing or nonnumeric values and geometry outside the intended 0 to 90 degree range, while explaining the model assumptions.

Practice and evidence: Create six input tests including 0, 30, 90, invalid text and out-of-range angles.

Thursday: Design for 255px width

Focus: Design for 255px width.

Learn: A readable narrow interface needs short labels, wrapping explanations, keyboard navigation, and a text alternative to diagrams.

Practice and evidence: Sketch an accessible ray-model tool with a text result.

Friday: Document a model prototype

Focus: Document a model prototype.

Learn: Technical documentation should explain angle convention, tested behavior, and what an idealized reflection tool cannot establish.

Practice and evidence: Submit pseudocode, wireframe, test log and model limitations. Rubric: geometry 6, tests 6, access 5, notes 3.
