Week 13 · Technology, Design & Tools

Volume and Three-Dimensional Modeling

How can 3D models solve real problems?

Monday: Represent a 3D dataset

Focus: Represent a 3D dataset.

Learn: A model record needs length, width, height and units. Its volume is l×w×h; a 2×3×4 cm object occupies 24 cm³.

Practice and evidence: Write a table of three imaginary storage boxes with dimensions and calculated volumes.

Tuesday: Code a volume calculator

Focus: Code a volume calculator.

Learn: An offline algorithm can multiply length, width and height, then label the output in cubic units.

Practice and evidence: Write pseudocode for volume=l*w*h, and evaluate 2×3×4.

Wednesday: Validate fractional inputs

Focus: Validate fractional inputs.

Learn: A program should accept positive fractional dimensions but reject missing, zero or negative values in this simple model.

Practice and evidence: Develop six test cases including 2×1.5×3=9 cm³ and a text error for invalid values.

Thursday: Design a narrow-screen tool

Focus: Design a narrow-screen tool.

Learn: A 255px-wide calculator must provide wrapping labels, a keyboard-accessible submit button and readable cubic-unit output.

Practice and evidence: Sketch an accessible mobile layout and a screen-reader-friendly result sentence.

Friday: Certify the paper prototype

Focus: Certify the paper prototype.

Learn: A design log records the formula, correct examples, errors and one revision.

Practice and evidence: Submit pseudocode, input table, 255px wireframe and test log. Rubric: math 6, tests 6, access 5, documentation 3.
