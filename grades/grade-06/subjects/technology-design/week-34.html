Week 34 · Technology, Design & Tools

A++ Big Question Capstone Research

What serious question can I investigate with evidence, calculation, and design?

Monday: Define tool requirements

Focus: Define tool requirements.

Learn: Prototypes begin with a user need, input/output boundaries and privacy constraints.

Practice and evidence: Specify an offline fictional classroom-resource tracker.

Tuesday: Build a data schema

Focus: Build a data schema.

Learn: Clear field names, units and missing-data handling reduce hidden errors.

Practice and evidence: Write a four-field mock dataset without real learner records.

Wednesday: Plan reproducible logic

Focus: Plan reproducible logic.

Learn: Algorithms should document assumptions, expected outputs and error cases.

Practice and evidence: Draft pseudocode for comparing a supply count with a fixed target.

Thursday: Test accessibility

Focus: Test accessibility.

Learn: Small screens, keyboard navigation and clear labels are core requirements.

Practice and evidence: Sketch a 255px layout and run four paper test cases.

Friday: Publish a prototype specification

Focus: Publish a prototype specification.

Learn: Versioned test evidence supports future repair and responsible reuse.

Practice and evidence: Submit data schema, pseudocode, usability checks and revision log. Rubric: correctness 6, documentation 6, access 4, privacy 4.
