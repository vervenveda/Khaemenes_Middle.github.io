Week 20 · Technology, Design & Tools

Cells, Systems, and Scientific Models

How do small structures support living systems?

Monday: Model a cell dataset

Focus: Model a cell dataset.

Learn: A cell diagram can record structure names, functions and whether each is present in the modeled cell type.

Practice and evidence: Build a fictional dataset with fields for structure, cell type, function and source note.

Tuesday: Validate labels

Focus: Validate labels.

Learn: A labeling tool should reject empty labels and flag a mismatch when a chloroplast is shown in a standard animal-cell model.

Practice and evidence: Write validation pseudocode for a simplified plant-versus-animal cell chart.

Wednesday: Represent scale

Focus: Represent scale.

Learn: A simple digital drawing is not necessarily to scale. If dimensions are hypothetical, labels must make that clear.

Practice and evidence: Prepare three tests for scale captions and diagram legends.

Thursday: Design offline access

Focus: Design offline access.

Learn: At 255px width, a labeling interface needs readable text, focus order and a nonvisual list of structures.

Practice and evidence: Sketch a narrow-screen offline cell-model page and printable text alternative.

Friday: Document testing

Focus: Document testing.

Learn: A technical learning artifact includes correct labels, accessible presentation, tests and limitations.

Practice and evidence: Submit the data schema, six tests and wireframe. Rubric: accuracy 6, tests 6, access 5, documentation 3.
