Week 23 · Technology, Design & Tools

Weather, Climate, and Human Patterns

How can patterns help communities prepare for change?

Monday: Create a weather dataset

Focus: Create a weather dataset.

Learn: An offline table stores dates, temperatures in °C and precipitation in mm. Classroom data should be explicitly marked simulated.

Practice and evidence: Build a four-row sample table with units, dates and source-type labels.

Tuesday: Compute a mean

Focus: Compute a mean.

Learn: For fictional temperatures 18,20,22,20 °C, the mean is 20 °C. A four-day mean is not a climate normal.

Practice and evidence: Write pseudocode summing numeric entries and dividing by the count.

Wednesday: Validate time windows

Focus: Validate time windows.

Learn: A software chart should distinguish day-level weather from decades-long climate statistics and reject missing units or dates.

Practice and evidence: Develop six test cases covering invalid data, incorrect units and valid averages.

Thursday: Design 255px-accessible charts

Focus: Design 255px-accessible charts.

Learn: A narrow-screen graph needs wrapped titles, readable axis values, and a text table so users can interpret it without color.

Practice and evidence: Sketch an offline weather chart and alternative table for 255px width.

Friday: Test and explain limitations

Focus: Test and explain limitations.

Learn: A reliable classroom prototype logs expected values, validation results and warnings against treating fictional data as live forecasts.

Practice and evidence: Submit code logic, test log and mobile wireframe. Rubric: math 6, tests 6, access 5, notes 3.
