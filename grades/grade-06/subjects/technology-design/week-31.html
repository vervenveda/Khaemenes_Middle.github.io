Week 31 · Technology, Design & Tools

Arts, Media, and Message Design

How do artists and media makers shape meaning?

Monday: Identify source metadata

Focus: Identify source metadata.

Learn: Digital assets need titles, creators, dates and rights information where available.

Practice and evidence: Create a source log for three fictional media assets, flagging unknown entries.

Tuesday: Explain file formats

Focus: Explain file formats.

Learn: Text, image and sound formats have different accessibility and offline tradeoffs.

Practice and evidence: Choose a compact offline format for a fictional captioned exhibit and explain the choice.

Wednesday: Prototype responsive design

Focus: Prototype responsive design.

Learn: A 255px-width layout still needs readable headings, labels and uncut words.

Practice and evidence: Sketch a narrow-screen three-card media gallery with text alternatives.

Thursday: Test accessible playback

Focus: Test accessible playback.

Learn: Useful controls can work by keyboard; motion and sound should not be required for comprehension.

Practice and evidence: Prepare test cases for missing captions, reduced motion, muted sound and long labels.

Friday: Release a responsible gallery

Focus: Release a responsible gallery.

Learn: Publication should preserve attribution and exclude private student records.

Practice and evidence: Submit an offline gallery mockup and source/accessibility checklist. Rubric: metadata 6, usability 6, privacy 4, reflection 4.
