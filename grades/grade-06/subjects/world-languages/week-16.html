Week 16 · World Languages & Global Culture

Forces, Motion, and Systems

How do forces and systems explain motion?

Monday: Name motion

Focus: Name motion.

Learn: Spanish movimiento means motion, fuerza means force, and velocidad means speed. A scientific translation needs precise labels and units.

Practice and evidence: Create a checked bilingual glossary with speed, time, direction, force and distance.

Tuesday: Describe direction

Focus: Describe direction.

Learn: Spanish adelante means forward and atrás means backward in common contexts; whether an object moves toward the observer depends on viewpoint.

Practice and evidence: Caption a fictional object moving along a labeled path using two-language direction phrases.

Wednesday: Calculate speed

Focus: Calculate speed.

Learn: A model travels 12 meters in four seconds, so its average speed is 3 m/s. The numeric result stays the same across language translations.

Practice and evidence: Write a two-language explanation preserving numbers and meters-per-second units.

Thursday: Compare motions

Focus: Compare motions.

Learn: Spanish más rápido means faster and más lento means slower; compare explicitly stated speeds rather than inferring forces.

Practice and evidence: Compare fictional objects traveling at 3 m/s and 2 m/s using complete sentences.

Friday: Create a bilingual motion guide

Focus: Create a bilingual motion guide.

Learn: A reliable translation includes correct scientific terms, clear graph labels and a note about contexts requiring clarification.

Practice and evidence: Submit a bilingual motion chart and five-sentence explanation. Rubric: vocabulary 6, math 5, clarity 5, checking 4.
