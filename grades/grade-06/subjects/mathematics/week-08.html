Khaemenes Academy · Grade 6 · Week 08 Mathematics

Expressions and Algebraic Thinking

How can symbols represent quantities, operations, and meaningful relationships?

Learning targets

Distinguish expressions from equations; translate words into symbols; substitute positive and negative values; apply order of operations; use the distributive property; combine like terms; and interpret expressions with units. Vocabulary: variable, coefficient, constant, expression, equivalent, substitution, distributive property. All core explanations are available offline.

Monday — Variables and expressions

A variable is a symbol representing a number. The expression 3x + 4 means three times x, then add four. An expression has no equals sign; an equation states equality. If x = 5, substitute: 3(5) + 4 = 19.

Guided: translate “seven more than twice a number” into 2n + 7. Explain why 7 + 2n is equivalent, but 2(n + 7) is not. Practice: (1) write four fewer than 5t; (2) evaluate 2x + 7 when x = 6.

Tuesday — Substitution and order of operations

Substitute each variable's value before simplifying. Grouping, exponents, multiplication/division, then addition/subtraction apply. For a = 3 and b = 4, calculate 2a² + b = 2(9) + 4 = 22—not (2a)² + b = 40.

Guided: Evaluate 4x − 2(y + 1) for x = 5 and y = 2: 20 − 6 = 14. Practice: (3) evaluate 3p² − 2 for p = 4; (4) evaluate 2(m + 3) for m = −1; (5) explain why 4 + 3 × 2 is 10, not 14.

Wednesday — Equivalent expressions and models

The distributive property states a(b + c) = ab + ac. For 3(x + 4) = 3x + 12, imagine three identical boxes, each containing x counters and four more counters; all three boxes contain 3x + 12 counters. Combine like terms: 2x + 5x − 3 = 7x − 3.

Guided: The area of a rectangle 4 units tall and (x + 2) units wide is 4(x + 2) = 4x + 8 square units. Practice: (6) expand 5(n + 3); (7) simplify 6y − 2y + 8; (8) explain why 2(x + 3) and 2x + 3 are not equivalent using x = 1.

Thursday — Context, units, and error analysis

A fictional community center charges $12 to register for an activity plus $3 per session. Total cost in dollars is C = 12 + 3s, where s is the number of sessions. For six sessions, C = 12 + 18 = $30. The model assumes one registration fee, a constant rate, and no taxes or discounts.

Independent: (9) find the price for nine sessions; (10) write a rule for $8 base fee plus $5 per visit; (11) a student claims 4(x + 2) = 4x + 2. Diagnose the error and correct it; (12) evaluate 5 − 2z for z = −3. Check with parentheses around negative numbers.

Friday — Mastery evidence and explanation

A (2 points): Translate “three less than four times n” into an expression and evaluate for n = 5. B (3 points): Evaluate 2a² + 3b for a = 3 and b = −2; show substitution and order. C (3 points): Prove 5(x + 2) and 5x + 10 are equivalent using a model or distributive property and a numerical check. D (2 points): Write and evaluate a model for a $10 entry fee plus $4 per visit, with seven visits.

Teacher-reviewed evidence totals 10 points; 8/10 meets the lesson's 80% standard but does not write verified scores or unlock curriculum. If below 80%, review the relevant worked example, correct an error with explanation, and use the authorized assessment for verified progression.
