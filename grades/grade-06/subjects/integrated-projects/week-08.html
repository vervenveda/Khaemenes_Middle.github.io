Week 08 · Integrated Research Projects

Expressions and Algebraic Thinking

How can symbols represent ideas in math, language, and culture?

Monday: Define a symbolic design problem

Focus: Define a symbolic design problem.

Learn: A fictional school garden has n rows with four plants in each row plus two extra pots. Its total count is 4n+2. Modeling assumes each row contains the same number.

Practice and evidence: Write an original design question for n=3 and draw the garden layout.

Tuesday: Build a value table

Focus: Build a value table.

Learn: Substitution turns a symbolic representation into a numerical prediction. For n=1, 2, 3, the totals 4n+2 are 6, 10 and 14.

Practice and evidence: Prepare a table with n, expression, and total, keeping each row traceable to the equation.

Wednesday: Contrast equivalent expressions

Focus: Contrast equivalent expressions.

Learn: The expression 4n+2 is not equivalent to 2(2n+2), because the latter adds four. A diagram helps test whether two written instructions produce the same outcome.

Practice and evidence: Evaluate both at n=1 and n=3; explain the mismatch and propose the corrected 2(2n+1).

Thursday: Explain design constraints

Focus: Explain design constraints.

Learn: A mathematical model can calculate quantities but not automatically establish soil suitability, cost, or access. These are unanswered design constraints.

Practice and evidence: Write a short design brief describing what 4n+2 predicts and three real-world factors it does not address.

Friday: Defend the model

Focus: Defend the model.

Learn: A completed project connects an accurate expression, representative diagram, test cases, and a revised design explanation.

Practice and evidence: Submit a fictional garden diagram, value table, equivalence check and reflective design note. Rubric: algebra 6, evidence 5, explanation 5, revision 4.
