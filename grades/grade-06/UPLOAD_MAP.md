# Upload Map — Grade 06

This ZIP contains a top-level folder named:

`grade-06/`

For the Khaemenes Middle School or Elementary repository transition, upload the contents to:

`grades/grade-06/`

The folder should contain:

- index.html
- README.md
- LICENSE.md
- UPLOAD_MAP.md
- VALIDATION.md
- assets/
- data/
- subjects/
- weekly-plans/
- printables/
- assessments/
- teacher-tools/
- records/
- docs/

Important: Do not upload these files into the repository root unless you intentionally want Grade 06 to replace the main school homepage.

Dependency rule: no CDN fonts, outside scripts, outside curriculum embeds, outside worksheet images, or required external assets.
